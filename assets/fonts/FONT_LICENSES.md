# Bundled font licences

All fonts in this folder are redistributable open-licence fonts:

| Family | Licence |
|---|---|
| Carlito, Caladea (Google CrOS core fonts) | SIL Open Font License 1.1 |
| Liberation Sans / Serif | SIL Open Font License 1.1 |
| Poppins (Indian Type Foundry) | SIL Open Font License 1.1 |
| DejaVu Sans / Serif | Bitstream Vera / DejaVu free licence (permissive) |

They are embedded in generated PDFs. DOCX files reference metric-compatible
system fonts (Calibri, Cambria, Arial, Times New Roman, Verdana, Georgia, Century Gothic).
